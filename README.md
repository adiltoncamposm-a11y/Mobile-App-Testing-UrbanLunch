# Mobile Application – Lunch Delivery QA Testing

## Project Overview

Manual testing of an Android food delivery application. The project focused on validating the complete user flow from selecting a pickup location and ordering dishes to tracking and completing the order.

### Testing Scope

* Pickup point selection
* Restaurant selection
* Dish selection and quantity management
* Dish details
* Order confirmation
* Order tracking
* Delivery time and cooking time
* Order completion
* UI and layout validation
* Screen rotation and state persistence
* Navigation between screens

### Testing Types

* Functional Testing
* UI Testing
* Exploratory Testing
* Regression Testing
* Mobile Testing
* Usability Testing

### Tools

* Android Studio
* Jira
* Android Emulator
* Test Case Design
* Equivalence Partitioning
* Boundary Value Analysis
