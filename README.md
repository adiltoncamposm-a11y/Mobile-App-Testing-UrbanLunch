# Mobile Application – Lunch Delivery QA Testing

## Project Overview

Manual testing of an Android food delivery application. The project focused on validating the complete user flow from selecting a pickup location and ordering dishes to tracking and completing the order.

## Testing Scope

- Pickup point selection
- Restaurant selection
- Dish selection and quantity management
- Dish details
- Order confirmation
- Order tracking
- Delivery time and cooking time
- Order completion
- UI and layout validation
- Screen rotation and state persistence
- Navigation between screens

## Testing Types

- Functional Testing
- UI Testing
- Exploratory Testing
- Regression Testing
- Mobile Testing
- Usability Testing

## Tools

- Android Studio
- Android Emulator
- Jira
- Test Case Design
- Equivalence Partitioning
- Boundary Value Analysis

## Test Execution

- Test cases designed: **36**
- Test cases executed: **36**
- Bugs found: **7+**

## Test Results

The test cases were executed on an Android emulator using Android Studio. Defects found during testing were documented in Jira with reproduction steps, expected and actual results, and supporting evidence.

## Defects

**7+ defects were identified and reported in Jira.**

Bug reports include:

- Reproduction steps
- Expected result
- Actual result
- Severity
- Screenshots and supporting evidence

- Designed test cases based on application requirements.
- Applied Equivalence Partitioning and Boundary Value Analysis.

- Documented defects in Jira with supporting evidence.
- Performed regression testing after defect fixes.
